# Performance Assessment of Portuguese Water Utilities

Two-part group project developed for Statistical Methods in Data Mining at Instituto Superior Técnico, Universidade de Lisboa.

## Overview

This project examines non-revenue water and real water losses in Portuguese water utilities using regulatory data from ERSAR. The two reports address complementary questions: which variables are associated with performance, and how performance should be measured and classified across utilities with different characteristics.

## Part I: Statistical Analysis and Predictive Classification

The first report analyses data from 2020 and 2023, explores differences between utilities and performance categories, and evaluates classification methods.

Topics include:

- Data preparation and exploratory analysis in R.
- Comparison of non-revenue water and real-loss indicators.
- Structural and operational variables associated with performance.
- K-nearest neighbours and Naive Bayes classification.
- Evaluation using measures including balanced accuracy and log-loss.

[Read Report I](reports/report-1.pdf)

## Part II: Alternative Indicators and Performance Categories

The second report examines intensity-based indicators intended to account for differences in network size and service structure. It uses regression analysis to study associated factors and compares alternative classification schemes.

A central discussion concerns the limitations of purely quantile-based categories: a utility may rank relatively well even when sector-wide performance is poor. The report proposes a hybrid classification approach combining an ERSAR regulatory reference with empirical thresholds.

[Read Report II](reports/report-2.pdf)

## Scope

These reports are academic analyses of regulatory data. The proposed indicators and classification schemes are coursework proposals, not official ERSAR standards. Sample size and differences between utilities limit the generalisation of the findings.
